# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately, by either:

- the **Report a vulnerability** button in this repository's **Security** tab (GitHub private vulnerability reporting), or
- email to **contact@hubfolks.com**.

Please include what you found, the steps to reproduce it, the affected version, and its possible impact.

## What to expect

HubFolks is maintained by a single developer during a free beta. You can expect:

- an acknowledgement within 7 days;
- a first assessment and, when the report is confirmed, a fix plan shortly after;
- credit in the release notes if you wish.

There is no bug bounty.

## Scope

- the HubFolks desktop and mobile apps;
- the HubFolks plugins;
- the HubFolks server (`api.hubfolks.com`) and website (`www.hubfolks.com`).

Only the latest released version is supported.
